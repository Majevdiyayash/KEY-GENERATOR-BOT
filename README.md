# SPANIX Key Bot — Discord License Manager

Advanced Discord License Manager Bot for SPANIX Security System.

## Features
- `/genkey`: Generate license keys with custom duration & count
- `/keyinfo`: Inspect license key details & status
- `/resethwid`: Reset HWID binding
- `/bankey` & `/unbankey`: Manage key suspension
- `/deletekey`: Revoke keys
- `/packages`: List available packages
